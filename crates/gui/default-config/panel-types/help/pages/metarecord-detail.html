Metarecord detail panel

Shows one metarecord — the record under the cursor in the metarecord list — with all its fields, and lets you edit them. Fields form a multi-map: several fields may share a name.

Values and types

Each value has a type: string, int, float, bool, datetime, a reference (ref) to another metarecord, a tree reference (tree_ref, e.g. mfr_path), and a few others. A value can also be Nothing — an explicit "does not apply", distinct from the field simply not existing. Reference and tree fields are filled with a value picker rather than by typing a UUID.

Editing

Move between fields with the arrows / j/k. Then:

Enteredit the field value under the cursor
a / dadd a field / delete the field under the cursor
Ctrl+n / Ctrl+screate a new record / save changes

The command-input m family does the same from either the detail or the list panel, with completion: m s set, m a add value, m v edit value, m d delete value, m n rename, m t retype. See the keyboard shortcuts for the full family (including the m b * bulk edits that act on the list selection).

Note: mfr_* fields are daemon-managed; overwriting one needs an explicit force.
