Log panel

The repository's event log. Every write goes through it — one revision per change, each holding the individual operations and their before/after snapshots — so the whole history is reviewable and reversible.

Browsing

Move through revisions with the arrows / j/k; Enter expands a revision to show its operations. Watcher, reconcile and manual edits all appear here.

Undo / redo

Ctrl+z (log:undo) and Ctrl+Shift+z (log:redo) move HEAD one revision back / forward on the active repository, restoring field values and versions exactly. Navigation is atomic: it computes the shortest path between where HEAD is and where you asked to go, so you can jump to any point, not just step linearly.

Beyond the panel

The CLI exposes the rest: mf log list to read history, mf log rollback to move HEAD (with a coordinated file-move policy), and mf log prune to compact old history. A rollback that would overwrite a file on disk routes the loser to the trash first.
