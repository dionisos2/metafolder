Keyboard shortcuts

Every action is a command; a keybinding is just a shortcut that dispatches one. Bindings live in a single file, ~/.config/metafolder/gui/keybindings.toml — the complete set, editable through config:open (which also shows the config paths). The keys in the tables below are read from that file as it stands right now, so they are your keys: rebind something and this page says so.

How keys are matched

  • A binding is a combo (ctrl+z) or a sequence of combos typed in turn (s l, m b s). While a sequence is pending the status bar lists the possible continuations; Escape cancels it.
  • Most keys are scoped to the focused panel type (the same combo does different things per panel), so navigation feels the same everywhere. A few are global.
  • Keys do not fire while a text field has focus, unless the binding opts in (the editing:* and status:clear keys do).

The m sequences edit fields from the command input, with completion (they work from both the list and the detail panel): m s set · m a add value · m v edit value · m d remove one value · m u unset the field · m n rename · m t retype. The bulk variants act on the whole selection: m b asks which operation, and m m s set · m m a add · m m v remove a value · m m r unset · m m d delete the metarecords name it up front.

Duplicates

Enterexpand a group into its copies (again on a copy: collapse)
Shift+kkeep the copy under the cursor — the group's other copies go to the trash (confirmed, and it lists them first)
Deletetrash the copy under the cursor, and only it

A group whose copies are down to one is dropped from the list: a lone file is not a duplicate of anything. + in front of a copy means it shares an inode with another copy in the same group — removing that name frees no space.

Event log

Enterexpand a revision into its operations (the cursor then walks them, and a revert aims at the one under it)
Shift+rrevert what is selected — the revision, or one operation of it — in place
Shift+o / Shift+vnarrow the revert to one operation / widen it back to the whole revision
Shift+drevert it together with whatever blocks it (the dependency closure)
Shift+llabel the revision (or clear its label)
Shift+gdraw every branch instead of the active line

Undo is Ctrl+z from anywhere, not only in the panel: it undoes the newest change you made, rolling HEAD back when that is the last thing in the log and reverting in place when the watcher has written since. Ctrl+Shift+z takes that undo back the same way. See the log panel.

Changing a binding

Open config:open and use the keybinding editor, or edit keybindings.toml and re-run metafolder-sync-config. A key maps to a single binding, or to an array of per-panel bindings (when = "<panel-type>"); text-input = true lets it fire while typing. set upserts and remove unbinds. Whatever you change, the tables above follow: they name the command and read the key back from the live table, so a command you unbind reads unbound here rather than a key that no longer works.
