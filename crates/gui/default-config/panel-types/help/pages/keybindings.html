Keyboard shortcuts

Every action is a command; a keybinding is just a shortcut that dispatches one. Bindings live in a single file, ~/.config/metafolder/gui/keybindings.toml — the complete set, editable through config:open (which also shows the config paths). The tables below are the shipped defaults.

How keys are matched

  • A binding is a combo (ctrl+z) or a sequence of combos typed in turn (s l, m b s). While a sequence is pending the status bar lists the possible continuations; Escape cancels it.
  • Most keys are scoped to the focused panel type (the same combo does different things per panel), so navigation feels the same everywhere. A few are global.
  • Keys do not fire while a text field has focus, unless the binding opts in (the editing:* and status:clear keys do).

The m sequences edit fields from the command input, with completion (they work from both the list and the detail panel): m s set · m a add value · m v edit value · m d delete value · m n rename · m t retype. The bulk variants act on the whole selection: m b s set · m b a add · m b r remove.

Changing a binding

Open config:open and use the keybinding editor, or edit keybindings.toml and re-run metafolder-sync-config. A key maps to a single binding, or to an array of per-panel bindings (when = "<panel-type>"); text-input = true lets it fire while typing. set upserts and remove unbinds.
