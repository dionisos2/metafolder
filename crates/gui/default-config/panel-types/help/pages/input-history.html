Input history

Every text zone — the command input, the shell (!) input, and panel text fields — keeps a persistent history, per repository and per zone. It is a GUI feature (stored under .metafolder/gui/history/); the daemon plays no part. Confirmed entries are appended, one per line.

Recall keys

These three keys are attached to the input directly (they work while you type):

Ctrl+p / Ctrl+n walk back / forward through the zone's entries, readline-style. Your in-progress draft is kept at the newest position and restored when you walk past it; making a real edit resets the walk.
Ctrl+r an fzf-style search overlay: entries newest-first, deduplicated, filtered by ordered-substring matching. Ctrl+p/Ctrl+n or the arrows move the selection, Enter inserts it, Escape (or losing focus) cancels.

These keys are not in keybindings.toml. Binding ctrl+p, ctrl+n or ctrl+r there with text-input = true would shadow them.
