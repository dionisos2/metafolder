Recent panel

Lists the metarecords you have viewed most recently in this repository, newest first, with how long ago each was viewed. Recency is tracked GUI-side (the daemon plays no part); opening a row publishes the selection just like the metarecord list, so a companion detail or file panel follows it.

Two ways to use it

  • As a picker — press g r ("go recent") from any panel to open the recent list in the command input, filtered by ordered substring as you type; Enter jumps to the highlighted record.
  • As a panel — t v (or panel:set type recent) shows it in a slot. Navigate with ↑ or k / ↓ or j, Enter or → opens the record, r refreshes, and f jumps to a row by name (see find).
