Log detail panel

Shows what a revision of the log changed, field by field. Put it in the other slot (T E) and it follows the log panel's cursor: a revision shows its operations, an operation of an expanded revision shows that operation alone (the Whole revision button, log-detail:toggle whole, widens it back).

Reading an operation

Each operation names its type, the field it wrote and the metarecord it wrote it on, with that metarecord's current path. Clicking the uuid selects the metarecord and shows it in the other slot. Below, a table pairs each field's values before and after the operation: removed values are struck through, new ones highlighted, and a path value (mfr_path, a tag) is shown as the path it names.

Fields the operation recorded without changing them are hidden; the Unchanged fields checkbox (log-detail:toggle unchanged) lists them too.

Large revisions

A reconcile writes one revision holding every file it found. The panel fetches its operations a hundred at a time — Show more operations fetches the next ones — and an operation selected in the log is fetched on its own.
