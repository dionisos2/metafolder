File panel

Previews a single file together with its metarecord fields. It follows the selection — open a file from the file manager or the metarecord list, and the arrows keep driving that list's cursor while the preview updates.

Browsing folders

A folder is shown as a thumbnail grid: click a tile to drill into a subfolder or preview a file. Backspace (the header's ←) goes back up a level — and it works on a plain preview too, showing the folder the file is in, so you can browse from here without going through another panel. Selecting something elsewhere takes over again.

Media preview

Images show inline. A video or an audio file shows its poster frame instead, and the player is built only when you ask for it — space, or a click on the poster. Loading a player makes the WebView build a decoding pipeline, and one that stalls (a machine with no GPU, a heavy stream) freezes the whole window, so nothing decodes until you say so. Posters come from ffmpeg, out of process and cached; audio, with no frame to extract, shows its type glyph.

When you do ask for playback the panel probes support first (sinks and per-file decoders) and says which decoder is missing instead of playing — never risking the WebView on a codec that is not there.

Playing audio and video

The transport keys are a media player's (mpv's), and do nothing when the preview is not showing audio or video. space in front of a poster is what loads the player and starts it. Each has a command, so they are rebindable like everything else.

spaceplay / pause
← / →seek 10 s back / forward
shift+← / shift+→seek 60 s back / forward
[ / ]slower / faster
shift+backspaceback to normal speed (plain backspace goes up a level)
shift+↑ / shift+↓louder / quieter
ctrl+mmute / unmute (plain m opens the metarecord-edit sequence)

A video resumes where you stopped watching: the position is kept on the file's metarecord as a playback_position field, and the toolbar shows it (↩ 12:34). Barely-started and watched-through videos store nothing, so they start from the beginning.

See also: the metarecord detail panel for editing the fields shown here.
