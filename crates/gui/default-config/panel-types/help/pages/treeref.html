Tree reference panel

Navigates a TreeRef forest — the hierarchical references (such as mfr_path, the file tree) that organise metarecords into trees, one forest per field name. Paths are resolved by the daemon, never walked client-side.

Navigating

↑/↓ or k/jmove the cursor
Enter or →descend into the node
← or Backspacego up to the parent
Home / Endfirst / last node
rrefresh

Which forest it shows is chosen by its field (default mfr_path). Selecting a node publishes it, so it can drive a companion reference list — the metarecords pointing at the selected node.
