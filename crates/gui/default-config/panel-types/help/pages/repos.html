Repositories panel

Lists the repositories the daemon knows about and lets you load, unload and open them. Each workspace targets one repository as its active repo; every panel in that workspace works against it.

Loading

Loading a repository takes an exclusive lock on its database (one daemon per repo) and warms its caches in the background — a load task shows a progress bar, and the repo answers queries from the slower fallback engine meanwhile. Unloading releases the lock.

Open this panel with s r (or panel:set-type repos). Repositories are also managed from the CLI: mf repo list / init / load / unload.
