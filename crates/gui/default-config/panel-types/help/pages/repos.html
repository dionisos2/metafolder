Repositories panel

Lists the repositories the daemon knows about and lets you load, unload and open them. Each workspace targets one repository as its active repo; every panel in that workspace works against it.

Loading

Loading a repository takes an exclusive lock on its database (one daemon per repo) and finishes in the background — applying what the filesystem did meanwhile, starting the watcher. A load task shows a progress bar; the repo answers queries once it is done. Unloading releases the lock.

Init repo… and Load repo… open a form where the folder is typed (or picked with Browse…). Without a form, g l (repos:load) opens the folder picker straight away and loads what you pick.

Open this panel with t r (or panel:set type repos); g o picks a loaded repository from the command input. Repositories are also managed from the CLI: mf repo list / init / load / unload.
