Value picker

Typing a raw UUID to fill a reference field (ref) or a tree reference (tree_ref) by hand is impractical. Instead, a field-editing form opens a picker: a throwaway workspace you drive with the ordinary panels — a list, a tree explorer, and so on — then confirm the highlighted metarecord, which is handed back to the form.

How it works

  • Starting a pick opens the picker in the other slot, so the form you were editing stays visible. The picker's status bar shows a prompt telling you what to choose.
  • Navigate normally: highlighting a row selects it (nothing is committed yet).
  • Ctrl+Enter (pick:confirm) confirms and returns the selection; Ctrl+Escape (pick:cancel) — or just closing the picker — cancels. The slot's previous contents are restored either way.

Dedicated combos are used so plain Enter/Escape keep their normal meaning inside the picker's panels. In the metarecord list the finder auto-focuses in picker mode, so you can type to filter and Ctrl+Enter straight away.

What comes back

For a ref field the chosen UUID becomes the value. For a tree_ref the pick fills the parent; you then type the leaf name — e.g. picking the node /document/test and typing report yields /document/test/report.
