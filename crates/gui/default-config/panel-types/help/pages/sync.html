Sync panel

Synchronises metarecords between two repositories. You pick a source and a target, review what would change, resolve any conflicts, then run — all in one panel, driving the shared sync engine (no shell scripting needed).

The flow

  1. Pick two repositories and review the status — how the two sides currently differ.
  2. Review the plan — the operations that would be applied, grouped by kind, with a live red/green overlay so you can see additions and removals before committing to anything.
  3. Resolve conflicts — where both sides changed the same thing, edit the resolution inline.
  4. Run — apply the plan.

Open it with s y (or panel:set-type sync). Cross-repo sync is also scriptable from the CLI (mf sync plan / run / status).
