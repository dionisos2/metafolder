Trash panel

A per-repository trash bin: deleting a tracked file moves it here instead of destroying it, so nothing is lost by accident. It is a filesystem feature (blobs and manifests under .metafolder/internal/trash/), shared with the CLI's mf trash; the daemon has no part in it.

Sending files to the trash

Press Delete on the selection in a list, detail, tree or ref-list panel to trash the file behind the metarecord (confirmed). In the file manager, Delete trashes the highlighted file or folder itself — to the repo trash when a repository is active, otherwise permanently — so untracked entries can go too. A rollback that would overwrite an existing file routes the loser through the trash as well.

The panel

Lists the trashed entries. Navigate with the arrows / j/k, and:

  • restore (Enter) — put the entry back at its original path.
  • delete (Delete) — permanently remove the highlighted entry (confirmed).
  • empty — permanently remove everything.
  • r — refresh the list.

Pruning by age or size is available from the CLI (mf trash prune).
