*** Command names (non-exhaustive default set)

| Command              | Description                                    |
|----------------------+------------------------------------------------|
| =daemon:set url <url>= | Change daemon URL — the setting and the URL are asked in the minibuffer when not named |
| =workspace:new=      | Create a new workspace, assign to both slots   |
| =workspace:close=    | Close the focused slot's workspace (slot falls back to the previous workspace) |
| =workspace:rename=   | Rename the focused slot's workspace            |
| =workspace:goto=     | Move both panels to workspace N (parameter)    |
| =workspace:next=     | Move both panels to the next workspace         |
| =workspace:prev=     | Move both panels to the previous workspace     |
| =workspace:next slot= | Assign the next workspace to the focused slot only |
| =workspace:prev slot= | Assign the previous workspace to the focused slot only |
| =panel:split=        | Show the right slot (focused workspace if unassigned) |
| =panel:unsplit=      | Hide the non-focused slot (workspace preserved) |
| =panel:hide=         | Hide the focused slot (workspace preserved)    |
| =panel:toggle split= | Split when one slot is visible, unsplit when both are |
| =panel:focus next=   | Move focus to the other slot                   |
| =panel:set type <name>= | Switch focused slot to the named panel type |
| =panel:swap=         | Exchange the two slots' panel types            |
| =panel:toggle fullscreen=   | Toggle showing only the focused panel fullscreen (default =z=; escape also exits) |
| =reconcile:run=      | Trigger reconcile on the active repo           |
| =mf:duplicate scan=  | Scan the active repo for byte-identical files and record the groups — the GUI half of =mf duplicate scan=; progress in the [[*Task bar]], summary in the status bar (see [[*Duplicates]]) |
| =orphan:detect=      | Mark the active repo's orphaned metarecords =orphan = true= and unmark the rest (=POST /orphans/mark=) — the GUI half of =mf orphan detect=; the count lands in the status bar and the message log |
| =orphan:delete=      | Delete the metarecords carrying the marker (=POST /query/delete= over =orphan = true=), after a confirmation naming the count. Detection is *not* re-run: what is marked is what goes |
| =orphan:detect-delete= | =orphan:detect= then =orphan:delete=, one confirmation between the two — the convenience form for "find the records whose file is gone and be rid of them" |
| =mf:order= | Number the selected folder's direct children (=order_file= / =order_dir=) and mark the folder =order_numbered= — the GUI half of =mf order=; no prompt: the selected folder, or the selected file's folder (default =m o=) — see doc "Ordering a folder" |
| =ignore:list=        | Show the installed ignore presets and the target's active patterns in the =message= panel — see doc "Setting ignore patterns" |
| =ignore:add <preset>= | Append an ignore preset's patterns to the target directory (completes over the installed presets) |
| =ignore:remove <preset>= | Remove an ignore preset's patterns from the target directory |
| =ignore:set <preset>= | Replace the target directory's whole ignore set with a preset's patterns |
| =log:rollback=       | Rollback to the selected revision              |
| =log:revert=         | Revert what is selected — the revision, or one operation of it — in place (default =shift+r=) |
| =log:revert op=      | Narrow the revert to a single operation (default =shift+o=) |
| =log:revert revision= | Widen it back to the whole revision (default =shift+v=) |
| =log:revert with-dependents= | Revert it together with whatever blocks it (default =shift+d=) |
| =log:undo=           | Undo the newest change the user made, on the active repo (default =ctrl+z=) |
| =log:redo=           | Take the newest undo back, on the active repo (default =ctrl+shift+z=) |
| =log:prune=          | Prune the event log                            |
| =devtools:open=      | Open the WebKit inspector (replaces the suppressed native menu's Inspect Element) |
| =quit=               | Exit the GUI                                   |

** Reconcile

Moved to the wiki: doc "Running a reconcile".

=mf:duplicate scan= is the GUI half of =mf duplicate scan= (see
doc "Duplicates"): it calls
=POST .../duplicates/scan= (202 + task id) and, like =reconcile:run=, polls the
task only to know when it ends — live progress belongs to the [[*Task bar]].
Its options (=--min-size=, =--rehash=, a subtree) stay *CLI-only*, the way
=mf trash prune='s selectors do: the command runs the ordinary
whole-repository scan, which is what a bare invocation should mean. On
completion the status bar shows
="Duplicates: N groups, M files, 4.5G reclaimable."= and the full summary goes
to the =message= panel. A *cancelled* scan is reported as an outcome rather than
an error — the hashes and groups it wrote are kept.

The =full= phase reports *bytes* rather than files (see
doc "The duplicate scan"), so the
task bar formats this phase's counts as a size.

The *duplicates panel* (=panel:set type duplicates=, suggested default =t u=)
lists the groups — reclaimable space, size, member count, hash — worst first,
each expanding to its members' paths with a marker on those sharing an inode
with another member. It is an ordinary query view over
=mf_schema = "duplicate_group"= sorted on =mfr_duplicate_reclaimable=. Every
row is a metarecord selection — a member, or the group metarecord on a header
row — so =metarecord:trash= and the shared file actions apply as they do
anywhere else, and the detail panel can show a group's own fields.

Deleting duplicates is what one opens this panel for, so it owns two actions of
its own, detailed in doc "duplicates panel":
=duplicates:keep= (=shift+k=) trashes every copy of the group *except* the row
under the cursor, and =duplicates:trash= (=Delete=) trashes that row alone. Both
confirm first, both name what they touch, and both re-count the group they
emptied (dropping it when one copy is left) as the daemon does. Nothing deletes
a file implicitly and nothing picks a survivor for you — the surviving copy is
always the row the cursor is on.

=metarecord-list:query duplicates= works from the other direction: it sets the
panel's DSL query to =same(mfr_duplicate_group, <selected uuid>)=
(doc "Same-value matching"), which is how a
file's twins are reached without the caller ever handling a hash. It writes the
query into the *visible* DSL zone rather than overriding it invisibly, so the
result composes with everything else the box can express — =AND NOT <uuid>= for "the
others", an extra predicate to narrow it.
