#+TITLE: Roadmap

What is left to do, most urgent first. Done work is not kept here: it is in
the git history and the CHANGELOG. Deferred work is a wiki note with
=status: deferred= or =proposed= (=scripts/dev/doc ls --status deferred=; doc
"Version scope and non-goals").

* To discuss
Every deferred or proposed note, to be gone through one by one: build it, keep
it deferred, or drop it.

** Collapsing a revert to one operation per cell
doc "Collapsing a revert to one operation per cell": write one operation per
cell instead of one per reverted operation.

** Query cost model
doc "Query cost model": =POST /query/explain=, saying without running a query
what its work decomposes into. Entirely unimplemented (=POST /query/profile=
answers the measured half).

** Future task extensions
doc "Future task extensions": an explicit acknowledgement freeing a result
early; query progress with real counts.

** Storage open questions
doc "Storage open questions": readers that never block on KV (operations stay
sequential — decided September 2026), a KV bit-sliced index, page checksums,
id locality over time, a cold cache.

** Cross-machine sync
doc "Cross-machine sync": the remote =.metafolder/= brought local for the sync
and sent back, the remote locked meanwhile (a network filesystem is refused).

** Sync open questions
doc "Sync open questions": the batch-size defaults, matching records without a
position, the content changes a stamp cannot see.

** Configuration open questions
doc "Configuration open questions": installing without a source checkout, a
sync racing an editor, leaving a conflicted merge to your own git tools.

** Duplicate open questions
doc "Duplicate open questions": duplicate directories, near-duplicates,
keeping a decision on a group across scans.

** Schema open questions
doc "Schema open questions": sharing a schema between synced repositories,
full validation at creation, range constraints.

** Watcher open questions
doc "Watcher open questions": a per-repository choice of source.

** Platform open questions
doc "Platform open questions": Unicode normalisation of names, Windows long
paths, what a port to macOS or Windows would take.
