** TODO the query planner: the next choices
Built September 2026 from the cases profiling found, not from the old design
(the old adaptive planner stays a record: doc "Indexing architecture"): a deferred text leaf's
candidates narrowed by trigrams (=495ea1b=), and the first choice made on a
cost — an =osm= path's anchors cut by a rare earlier term (=1140e07=). What
is left, each to measure before building:
- an unsorted page under a large subtree: =FollowsTransitive= reads the
  root's whole descendant bitmap where a page wants 100 ids. Measured 7
  October 2026 (=query.folder= against =query.page=, a folder holding the
  whole repository): +0.08 ms on M (21 000 nodes), +0.4 ms on L (105 000),
  about 4 ms extrapolated to a million. The way out — a per-candidate
  ancestry check stopping at the page — costs ≈ 100 × depth × 2 µs ≈ 1 ms,
  so it loses below roughly 300 000 nodes, and its walk cannot be budgeted
  without the subtree's size, which the store does not keep. Not built;
- a two-term =osm= path whose earlier term is common: the bench's finder,
  still ≈ 5 ms on L, nearly all of it each anchor's ancestry (≈ 2 µs a random
  read). No bitmap formulation found cheaper on that shape;
- whatever the slow log shows next on a real repository: reads are logged per
  phase, a read is logged from 100 ms or 100 000 keys, and =mf slow replay=
  runs a logged query again for its phases now (doc "Slow log"). Read 9
  October 2026 on =benchmarks/real/=: no query, only =GET /watch= at 2–2.6 s
  from the GUI, which was waiting for the watch placement's lock (fixed);
  look again once that repository has run a while longer.

** TODO =daemon/src/sync.rs= =locate()= uses =Path::exists()=

that file ever becomes user-placeable.

* TODO shipped tagging scripts
** TODO the mock =mf= log loses argument boundaries
=scripts/lib/mf-mock.sh= (and =daemon-fixture.sh=) log each call as ="$*"=,
arguments joined by spaces, so an assertion glob can match text *inside* an
argument — a DSL query holds spaces. No false positive seen, and the log's
form is the interface of =mock_count= / =mock_calls_matching=: changing it
rewrites the hundred assertions of six suites. Deferred, cost above gain. If it
ever bites: keep =$*= as the readable log and write a second one, arguments
separated by =\x1f=, with a =mock_count_argv= for the assertions that need it.

** TODO =mf path= once per question in the tagging scripts
=gui-tag-folder.sh= and =gui-tag-pair.sh= call =mf path "$uuid"= for the preview
at each question, right after reading the same record's *relative* path
(=--resolve-tree mfr_path=). Only the repository's absolute root is missing to
build it without the round-trip. One HTTP call per keystroke of a human: not
felt. Clean fix: a CLI printing a repository's root (=mf repo root=, or a
=--root= on =mf repo list=, whose JSON would need =jq=), read once per run —
a CLI addition to weigh first.
